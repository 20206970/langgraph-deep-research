# P1.2 可观测性与 SSE 设计

## 目标

在不改变 P1.1 同步运行 API 语义的前提下，为研究图增加统一的本地事件、标准 SSE 输出和可选 LangSmith Trace。业务状态以 SQLite 为准，LangSmith 只用于诊断，SSE 只负责实时展示。

## 范围

- 新增结构化事件 envelope：`event_id`、`run_id`、`task_id`、`type`、`timestamp`、`payload`。
- 事件类型覆盖计划、任务启动/检索/重试/完成/失败、报告阶段和运行结束。
- 事件同时写入 `event_logs`，并通过进程内发布器供 SSE 消费。
- 保留现有 `/runs` 同步接口；升级 `/research/stream` 为标准 SSE，并沿用一键研究兼容流程。
- 增加 LangSmith 配置和可选 LangChain tracer，默认关闭；关闭、未配置或 tracing 失败不得影响研究流程。
- 事件和 Trace metadata 只允许保存运行标识、节点、模型、Prompt 版本、搜索源和重试次数等脱敏信息。
- 前端消费 SSE 事件，展示任务状态和错误摘要；报告正文仍使用现有 Markdown 渲染组件。

## 架构与数据流

1. `src/events.py` 定义事件类型、Pydantic envelope、脱敏函数、线程安全发布器和 SSE 编码器。
2. `SQLiteRepository` 暴露事件追加与查询接口，内部继续复用 `event_logs` 表。
3. `_execute_persisted_run` 或流式执行器按 `run_id` 注册发布器；图节点通过 `run_id` 查找发布器，不把回调写入 LangGraph State。
4. Planner、Summarizer、Reporter 在关键边界发布事件。搜索重试携带 `attempt`，错误只携带短摘要，不携带模型原文、完整报告、API Key 或认证头。
5. `/research/stream` 创建计划、自动确认并创建 run，然后按 `event: <type>`、`id: <event_id>`、`data: <json>` 输出事件；结束时发送 `completed` 或 `failed`。
6. LangSmith tracer 由 `TracingConfig` 构造，使用 `Client` 的 `hide_inputs`、`hide_outputs`、`hide_metadata` 和 sampling 配置；构造失败或发送失败只记录本地日志。

## LangSmith 策略

- 默认 `enabled=false`，只有显式开启且存在 API Key 时构造 tracer。
- `capture_content=false` 时隐藏输入和输出；即使开启内容采集，也先执行本地脱敏，禁止上传 API Key、Authorization/Bearer、完整私有文档和完整最终报告。
- metadata 仅包含 `run_id`、`session_id`、`task_id`、节点名、模型版本、Prompt 版本、搜索 provider、attempt 和 `redacted=true`。
- tracer 通过 LangChain `config.callbacks` 传入图执行；不改变业务状态和报告生成逻辑。

## SSE 契约

```text
event: task_completed
id: evt_xxx
data: {"event_id":"evt_xxx","run_id":"run_xxx","task_id":"task_xxx","type":"task_completed","timestamp":"...","payload":{"status":"succeeded","attempt":1}}
```

客户端按 `type` 更新任务状态；未知事件保留但不阻断连接。服务端异常输出 `failed` 事件并结束流，客户端不把网络断开误判为研究成功。

## 验收与测试

- 事件 envelope 字段、payload 脱敏和 SSE 编码有单元测试。
- Repository 事件追加/查询与运行 ID、任务 ID 关联有 SQLite 测试。
- Fake Graph/LLM 验证 tracing 关闭、LangSmith 构造失败时流程仍完成。
- API 测试验证标准 SSE 的 `event`、`id`、`data` 行和终态事件。
- 前端构建通过，收到任务完成/失败事件后状态可更新，最终报告仍正常渲染。

## 非目标

- 本阶段不把 `/runs` 改为后台任务，不引入分布式消息队列。
- 本阶段不把 LangSmith 作为业务状态源，不依赖网络可达性完成运行。
- 本阶段不上传完整网页正文、用户文档或最终报告内容。
